# 08 · 패키지 앱 데모영상 스크립트 (Galaxy S24+ 화면 녹화)

> 9 모듈 각 30~60초 짧은 클립 → 편집 시 합쳐 3~5분 통합 영상.
> 사장님께 DM 첨부·미팅 사전 시청용. 톤은 진솔·차분·"실제로 동작하는 데모".

---

## 0. 사전 준비 (10분, 한 번만)

### 0-1. 같은 와이파이 확인
- 맥 dev 서버: `http://10.50.1.120:3000`
- 갤럭시 사파리 X → 삼성 인터넷 또는 Chrome 권장
- 위 URL 접속해서 메인 페이지 뜨면 OK

### 0-2. 홈 화면 단축 아이콘 (선택)
- 갤럭시 Chrome: `⋮` 메뉴 → "홈 화면에 추가" → "유어라인 데모"
- 매번 URL 안 쳐도 됨. 첫 진입 1초 절약.

### 0-3. 디스플레이 설정 (녹화 중 잠금 방지)
- 설정 → 디스플레이 → 화면 자동 꺼짐 시간 → **10분 이상**
- 알림 → 방해 금지 모드 **ON** (녹화 중 카톡 알림 차단)

### 0-4. 화면 녹화 기능 위치
- 상단 알림창 두 번 내려서 빠른 설정 → "화면 녹화" 타일
- 첫 사용 시: 설정 → 해상도 **1080p · 60fps**, 마이크 **ON**, 터치 표시 **ON** (시연 손가락 위치 보이게)

### 0-5. 녹화 전 데이터 워밍업
- 메인 → `/c/sim` 한 번 열어두고 첫 컴파일 끝낸 뒤 다시 메인으로
- 콘텐츠·챗봇 페이지도 한 번씩 미리 열어 캐시
- 안 그러면 첫 진입 시 Turbopack 컴파일로 1~2초 흰화면

## 1. 공통 가이드라인

| 항목 | 기준 |
|---|---|
| 1 클립 길이 | 30~60초 (60초 넘으면 컷) |
| 종횡비 | **9:16 (세로)** — 갤럭시 기본 화면 그대로 |

## 2. 클립별 시나리오

### CLIP 0 — Intro · "사장님께 드리는 4주 베타 진단" (15초)

**시작**: 메인 `/` 풀그라데이션
**액션**:
1. 메인 진입 (1초)
2. 💕 "사장님 4주 베타 진단 리포트" 카드 탭
3. 리포트 첫 화면 (Hero) 보이면 1.5초 정지

**자막**:
> "유어라인 사장님께 드리는 4주 베타 진단"

**핵심 멘트** (사용자 녹음 시):
> "이 영상은 저희가 사장님을 위해 만든 4주 베타 패키지의 데모예요."

### CLIP 1 — ✨ AI 시뮬 (60초) ⭐ 가장 임팩트

**라우트**: `/c/sim`
**시작**: 메인 `/` 또는 `/c`

**액션**:
1. 메인 → 손님 카드 탭 → /c
2. "AI 시뮬레이션" 카드 탭 → /c/sim
3. 사진 1장 업로드 (사장 셀카·손님 셀카 — 미리 갤러리에 준비)
4. 시술 종류 6종 그리드에서 "글루 맥스" 또는 "C컬 영양펌" 탭
5. 마스크 그리기 영역에서 눈 위에 빠르게 brush stroke (4~5초)
6. "시뮬 시작" 버튼 → 진행률 바·단계 메시지 (사진 분석 → AI 그리기 → 디테일 → 마무리)
7. **결과 Before/After** 슬라이드 보이면 5초 정지

**자막**:
> "손님 셀카 1장 → AI 시뮬 5~10초"
> "동네 경쟁샵·체인 모두 없음"

**멘트**:
> "손님이 카톡으로 셀카 보내면 5초 만에 시술 결과를 AI가 그려서 답장해드려요."

### CLIP 2 — 💬 챗봇 (45초)

**라우트**: `/c/chat`
**시작**: `/c`에서 챗봇 카드 또는 메인 → 손님 → 챗봇

**액션**:
1. /c/chat 진입 → 인사말 보임
2. Quick reply "글루 연장 가격 알려주세요" 탭 → 응답 (3~5초 로딩)
3. 응답 도착 → 1.5초 정지
4. **직접 입력** "임산부도 가능한가요?" → Send
5. **노란색 escalation 버블** + "사장님 확인 요청 전달됨" 라벨 보이면 3초 정지

**자막**:
> "사장님 톤 그대로 학습"
> "알러지·임산부·환불은 자동으로 사장님께"

**멘트**:
> "시술 중 들어오는 카톡 70%를 챗봇이 처리해요. 위험 키워드는 자동으로 사장님께 알림."

## 3. 편집·합치기 (CapCut 모바일 권장)

### 3-1. 도구
- **CapCut** (무료, 한국어, 갤럭시 Play Store) — 추천
- 또는 VLLO, InShot

### 3-2. 합치는 순서
```
[CLIP 0 Intro 15s]
  → CLIP 1 AI 시뮬 60s   ⭐ 가장 임팩트 먼저
  → CLIP 2 챗봇 45s
  → CLIP 3 카드뉴스 45s
  → CLIP 4 콘텐츠 자동 60s
  → CLIP 5 알림톡 40s
  → CLIP 6 답글 자동 35s
  → CLIP 7 단골 회복 40s
  → CLIP 8 일간 1줄 25s
  → CLIP 9 대시보드 45s
[CLIP 10 Outro 25s]
```

**합산** ≈ 7분. 사장님 미팅 사전 시청용으로 적절.
**DM 첨부용 짧은 버전** 따로 만들고 싶으면: CLIP 0 → 1 → 3 → 10 만 합치면 약 2.5분.

### 3-3. 편집 팁
- 클립 간 전환: 단순 **컷** 또는 0.3초 페이드 (화려한 트랜지션 X)
- BGM: CapCut 무료 lo-fi · acoustic 한국 트랙 1곡 전체 깔기 (볼륨 25%)
- 자막: 모든 클립에 각 자막 1줄 (Pretendard Bold 흰글 + 핑크 outline)
- 색감 보정 X — 앱 자체 핑크 톤이 이미 강함
- 인트로·아웃트로에 유어라인 로고·핸드폰번호 워터마크 옵션

### 3-4. 내보내기
- 1080p 60fps · MP4 · 9:16
- 파일 크기 200MB 이내 (DM 첨부·메신저 호환)

## 4. 녹화 체크리스트 (모든 클립 공통)

녹화 전 한 번:
- [ ] 같은 와이파이 확인 (10.50.1.120:3000)
- [ ] 방해 금지 모드 ON
- [ ] 화면 자동 꺼짐 10분 이상
- [ ] 화면 녹화: 1080p · 60fps · 마이크 ON · 터치 표시 ON
- [ ] 배터리 50% 이상
- [ ] 카톡·메일 알림창 닫기
- [ ] 손가락 깨끗 (지문 흔적)

각 클립 전:
- [ ] 시작 라우트 한 번 미리 진입해서 컴파일 워밍업
- [ ] 데이터 상태 확인 (인박스 비어있지 않은지 등)
- [ ] 30초 안에 끝나도록 동선 머릿속 1회 시뮬

NG·재촬영 기준:
- 컴파일 로딩 흰화면 1초 이상 → 재촬영
- 손가락이 화면 핵심 가리면 → 재촬영
- 멘트 흐려졌으면 → 클립 끝 추가 녹음 후 편집
