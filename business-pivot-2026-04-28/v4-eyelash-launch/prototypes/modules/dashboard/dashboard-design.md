## 1. 사장 입장 UX 원칙 (5가지)

### 1-1. 모바일 1탭 우선 (사장 폰에서 즐겨찾기)
- **layout="centered"** → 가로 X (모바일 가로 스크롤 X)
- 세로 스크롤만 — 손가락으로 위→아래 자연
- 즐겨찾기 URL 1개 (예: `dashboard-uareline.streamlit.app`)

### 1-2. 숫자 우선, 차트 보조
- **st.metric** 큰 글씨 = 즉시 인식
- 차트는 마지막 섹션 (트렌드만)
- 사장은 30초 안에 핵심 파악 → 자세히 보고 싶을 때 트렌드 봄

### 1-3. 액션 가능한 정보를 위에
- 이탈 위험 단골 TOP 5 = **즉시 카톡 1탭 액션** 가능
- 단순 통계는 아래로 (단골 자산·매출 기여)
- 사장이 윗부분만 봐도 그 날 할 일 파악

### 1-4. 컬러·이모지로 인지 부담 ↓
- 핑크 톤 (#FFF8FA 배경 / #B85A75 헤딩 / #E89BAE 액센트) — 유어라인 워터마크 톤
- 이모지: 📊 💕 ✨ ⚠️ 💎 📈 — 섹션 즉시 구분
- 텍스트 wall 회피

### 1-5. commission 협상 근거 노출
- **단골 자산** (7년 누적 1,500만+) — "이 자산 회복이 commission 가치"
- **매출 기여** (베타 X일 +Y만) — 모듈별 추정 명시 → 의심 ZERO

## 3. KPI 7종 정의

| KPI | 정의 | 노출 위치 |
|---|---|---|
| **예약·노쇼·신규·재방문** | 일별 합계 | §1 오늘 한눈에 |
| **챗봇 응대 → 예약 전환** | 챗봇 1건 시작 후 → 24h 내 예약 매핑 | §1 오늘 |
| **✨ AI 시뮬 요청** | 카톡 셀카 → 시뮬 회신 1건 | §2 AI 시뮬 |
| **✨ 시뮬 → 예약 전환율** | (시뮬 후 예약 / 시뮬 요청) × 100% | §2 |
| **이탈 위험 점수** | 미방문일 (40) + 누적방문 (30) + 회원권 (20) + 메디핑크 패키지 (10) | §3 이탈 위험 |
| **단골 LTV** | 누적 방문 × 평균 시술 가격 + 회원권 가치 | §4 단골 자산 |
| **매출 기여 추정** | 모듈별 전환 건수 × 평균 가격 | §5 매출 기여 |

## 4. 데이터 흐름 (베타 운영 시)

```
[자동 수집 source 7종]
   ├─ 네이버 플레이스 후기 (Apify)
   ├─ 챗봇 응답 worker 로그
   ├─ ✨ AI 시뮬 worker 로그
   ├─ 알림톡 발송 (알리고 API)
   ├─ 인스타 인사이트 (Meta Graph API)
   ├─ 블로그 게시 (네이버 API)
   └─ 시술 기록 (사장 1탭)
            ↓
       Google Sheet "uareline-data"
       (일별 + 손님 + 시뮬 + 챗봇 + 후기 + 알림톡 + 회원권)
            ↓
       Streamlit Cloud (gspread fetch, 5분 캐시)
            ↓
       사장 모바일 1탭 → 대시보드 표시
```

### 5-2. 운영 시 데이터 fetch 코드 변경

```python
# Prototype: CSV
def load_daily_kpi():
    return pd.read_csv(BASE / "sample-daily-data.csv")

# 운영: Google Sheet
from streamlit_gsheets import GSheetsConnection
conn = st.connection("gsheets", type=GSheetsConnection)
def load_daily_kpi():
    return conn.read(worksheet="일별", ttl=300)
```

## 6. 사장 인터뷰 필요 항목 (현재 가설로 진행, 인터뷰 후 보강)

> **현재 prototype**: 가설 기반 6 섹션. 사장 인터뷰 후 실제 우선순위 재배치.

### 6-1. 사장이 매일 보고 싶은 것 (가설 → 검증 필요)

- [ ] **오늘 예약·노쇼** 즉시 확인 (가설 OK?)
- [ ] **이탈 위험 단골** 알림 (액션 가능 — 가설 OK?)
- [ ] **AI 시뮬 사용 횟수** (사장 호기심? 또는 무관심?)
- [ ] **매출 기여 추정** (commission 협상 시 봄 — 매일은? 주 1회면 충분?)
- [ ] **신규 후기·답글** 자동 처리 결과
- [ ] **인스타·블로그 게시 누적**

### 6-2. 사장 의문 가능 (대응 준비)

- "이 숫자 어디서 나왔어?" → Google Sheet URL 백업 카드 (사장 의심 시 공유)
- "노쇼 0 좋은데 진짜?" → 알림톡 발송 로그 확인 가능
- "이탈 위험 단골이 너무 많은데?" → 점수 임계 사장 의향 조정 가능
- "AI 시뮬 사용 수치가 이게 다야?" → 신규 손님 채널별 분해 가능

### 6-3. 미팅 시 확인할 디자인 항목

- [ ] 컬러 톤 (핑크 OK? 다른 선호?)
- [ ] 섹션 순서 (이탈 위험 위에 두는 게 맞나?)
- [ ] 단골 명단 노출 OK? (개인정보 — 닉네임 표시 vs 익명)
- [ ] 메디핑크 매출 분리해서 보고 싶은지

## 9. 정직한 한계 + 회피

### 9-1. 한계
- **추정 매출 기여**: 정확도 ~70% (실제 시술 가격·시술 차이 반영 안 됨)
- **이탈 위험 점수**: 임계값(D+45) 임의 — 사장 의향 받아 조정 필요
- **AI 시뮬 정확도 → 매출 기여**: 시뮬 → 예약 전환 매핑이 챗봇 1건과 중복 가능 → 이중 계산 risk
- **사장 인터뷰 X 상태**: 6 섹션이 가설 — 사장 미팅 후 우선순위 재배치 필수

### 9-2. 회피
- 모든 추정 값에 "추정" 라벨 명시 — 사장 신뢰 ↓ 회피
- 이탈 위험·매출 기여 모델은 베타 2주차에 1차 검증 → 사장 OK 받기
- 사장 인터뷰는 D-Day 미팅 시 30분 별도 확보 (디자인 미세 조정)
