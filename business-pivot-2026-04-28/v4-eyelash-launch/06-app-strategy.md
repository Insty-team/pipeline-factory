## 2. 핵심 전략 — 앱 중심 통합 (2026-05-22 결정)

### 2-1. 왜 앱 중심인가?

| 채널 | 장점 | 단점 |
|---|---|---|
| **카카오 채널 챗봇** | 손님 친숙 | 사장 분산 (앱·카카오·웹) / 데이터 silo |
| **앱 (Streamlit multipage)** ⭐ | 모든 기능 1탭 통합 / 데이터 단일 source / 사장·손님 UX 일관 / 데모 단순 | 손님 앱 설치 학습 비용 |

→ **앱 채택**. 학습 비용은 **첫 시술 할인 쿠폰 + AI 시뮬 무료**로 해결.

### 2-2. 손님 acquisition — 앱 설치 유인책

```
┌──────────────────────────────────────────────────┐
│  유어라인 앱 다운로드 안내                          │
│                                                    │
│  💕 첫 방문 손님 한정!                              │
│                                                    │
│  앱 설치하시면:                                     │
│  🎁 첫 시술 5,000원 할인 쿠폰                       │
│  ✨ AI 시뮬레이션 무료 사용                          │
│                                                    │
│  [앱 다운로드 →]                                    │
└──────────────────────────────────────────────────┘
```

배포 채널:
- 인스타 프로필 링크 (`@ure.line` 바이오)
- 블로그 모든 글 footer
- 카카오 채널 환영 메시지 (사장 채널 활용)
- 카드뉴스 16장 마지막 CTA
- 네이버 플레이스 "더 알아보기" 링크 (옵션)

### 2-3. 카카오 채널의 새 역할 — 알림톡 발송 only

| 사용 | 채널 |
|---|---|
| 손님 응대 (Q&A·시뮬·예약) | 🆕 앱 |
| 사장 자동 알림 (예약·노쇼·재방문 12종) | 카카오 알림톡 (변경 X) |
| 사장 캠페인 (메디핑크·이벤트) | 카카오 친구톡 (변경 X) |

→ 카카오 채널은 **발송 채널 only**. 손님이 보내는 메시지는 앱으로 유도.

## 3. 앱 구조 (Streamlit Multipage)

```
유어라인 앱  (uareline-demo.streamlit.app)
│
├── 🏠 홈 (역할 전환: 손님 / 사장)
│
├── 👩 [손님 View]
│   ├── ✨ AI 시뮬       (셀카 → J·C·D컬 비교, 무료)
│   ├── 💬 챗봇 응답    (30Q&A — 가격·디자인·알러지·세안 등)
│   ├── 📅 예약하기      (시뮬 후 자동 트리거 or 직접)
│   ├── 🎁 쿠폰         (첫 시술 5,000원 할인 — 신규 가입자)
│   └── 🎨 메뉴·디자인    (카드뉴스 16장 — 가격·컬 비교·메디핑크)
│
└── 💼 [사장 View]
    ├── 📊 대시보드      (KPI · 단골 자산 · 매출 기여 · 트렌드)
    ├── 📥 받은 요청    (예약 · 시뮬 · 답글 시안 · 챗봇 escalate)
    ├── 📸 콘텐츠       (사진 1장 + 메뉴 → 인스타·블로그 게시물 자동 생성·게시)
    ├── 📢 알림톡 매트릭스 (12종 자동 발송 + 테스트 발송)
    ├── 💌 답글 자동    (신규 후기 감지 + 답글 시안 → 사장 1탭 게시)
    └── 📅 일간 1줄     (오늘 요약 + 카톡 forward 텍스트)
```

→ **1 URL, 6+5 페이지**. 모바일·데스크탑 호환. 사장 모바일 즐겨찾기 1개.

## 6. 직접 방문 영업 — 5 전략 (저장 기록)

1. **타이밍**: 평일 화·수·목 점심 (12~13시) 또는 4타임 사이 휴식
2. **1분 안에 trust**: "유어라인 데이터 분석한 사람이에요" → 영업·다단계 의심 ↓
3. **사장 시간 방해 X**: "시술 중이시면 5분 후 카톡으로 자료 보내드릴게요"
4. **2-step 영업**: 첫 방문 = 진단 리포트 1장 전달 + AI 시뮬 5초 시연만. 30분 미팅 X
5. **2번째 컨택**: 24h 무응답 시 카톡 1줄 → 사장 답장 → 본격 미팅 약속

준비물: 진단 리포트 인쇄본 / 노트북 (앱·대시보드) / 폰 (앱 모바일 시연) / 명함

## 8. 미해결 결정 사항 (다음 세션에서 결정)

- [ ] 앱 배포 플랫폼 — Streamlit Cloud (무료) vs Vercel (더 깔끔하지만 React 필요)
  → **Streamlit Cloud 추천** (이미 인프라 있음, 빠른 데모 우선)
- [ ] AI 시뮬 inpainting 모델 — GPT-image-1 (정확도 80%) vs Stable Diffusion (5배 저렴, 정확도 70%)
  → **GPT-image-1 권장** (베타 4주 ~$50 — 정확도 우선)
- [ ] 답글 자동 — Apify Naver scraper 셋업 시점 (베타 시작 후 vs 데모 시점)
  → 데모는 mockup, 베타 시작 후 실제 셋업
- [ ] 첫 방문 시점 — 진단 리포트·앱 데모 완성 후 며칠 뒤 / 베타 D-Day 미팅 약속 잡고 가는지
  → Stage 1·2 완료 후 (1주 이내)
